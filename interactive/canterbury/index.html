Projected changes near Canterbury communities

Numbers are the median change across six individual climate models, measured at the nearest valid approximately 5 km grid centre. Cell colour shows how many models agree on the direction of change. Hover over a cell to see the lowest and highest individual models.

These are gridded model values near town centres, not weather station observations or SA2 averages. Click a community name to locate it on the map.

Climate indicator definitions

Choose an indicator to read its full definition, how it is calculated, the units used for projected change and what those changes mean. The currently selected indicator appears first and opens automatically.

Definitions and units are based on the Ministry for the Environment variable definitions, NIWA's 2024 technical guidance (Table 3), and the Core Public Dataset metadata.

About these projections

The map shows changes calculated from the six individual climate-model fields in the NIWA / Ministry for the Environment Core Public Dataset. Every value is a projected change from the modelled 1995–2014 reference period. Different variables have different units and different seasonal availability.

How the maps are calculated

Median: the median of six model changes at each original approximately 5 km grid centre. Agreement: the greater of the number of models showing an increase and the number showing a decrease. Zero changes count in neither direction. It describes agreement on the direction of change, not probability or statistical significance.

Lowest and highest models: the full spatial fields from the single models with the smallest and largest area-weighted mean change over Canterbury. Their identities can change with indicator, period, scenario and season. These are different from the minimum and maximum model values at a particular community.

Why the map is smooth

The source measurements are unchanged. Smooth interpolation is applied only to the coloured display image when the original grid is reprojected. The agreement layer uses nearest-neighbour resampling to keep model counts discrete. The map does not contain predictions at a finer resolution than the original grid. Map raster opacity can be adjusted to inspect location context underneath.

Colour scale and comparisons

Each map's colour legend covers the actual smallest and largest values across its valid Canterbury grid cells. Single-direction changes use a stronger single-colour palette; maps containing both increases and decreases use blue to red with a zero midpoint. Read the legend when comparing two selections, because colour intensity is scaled independently for each displayed map.

Communities

Mapped town-centre coordinates are used to find the nearest land grid centre in New Zealand Transverse Mercator (EPSG:2193). For every season, the community table shows the median across all six models; the hover details identify the lowest and highest at that town's sampled grid centre. The distance to the sampled grid cell is displayed. Where possible, populated-place coordinates are taken from the LINZ gazetteer served by Environment Canterbury; otherwise points are approximate town-centre references.

Projection and basemap

The original NetCDF rasters are tagged EPSG:4272. Geographic boundaries and community coordinates are transformed to the appropriate source and rendering reference systems. Coloured map images are reprojected to Web Mercator (EPSG:3857), the projection used by the Leaflet display. Canterbury and surrounding regional boundaries originate from Environment Canterbury GIS, which cites Statistics New Zealand. The default map uses OpenStreetMap Standard tiles without an API key, with the local Environment Canterbury boundary overlay. Turn off OpenStreetMap background to use the bundled local regional geography. A north arrow and labelled places help verify map orientation.

Scope and limitations

The visualised region is the Canterbury regional council area. It is not the full extent of Waitaki District outside Canterbury. The data are 20-year climate averages. Model agreement does not capture every source of uncertainty, and even unanimous directional agreement may correspond to a small change. These are climate-change projections rather than site-specific engineering hazard estimates.
